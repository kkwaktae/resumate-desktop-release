응용 프로그램
  1. 받은 DMG 파일 열기

    다운로드 폴더에서 Resumate의 .dmg 파일을 더블 클릭해요.

  2. 응용 프로그램 폴더로 옮기기

    Resumate 아이콘을 응용 프로그램(Applications) 폴더로 드래그해요.

  3. 응용 프로그램에서 실행하기

    복사가 끝나면 응용 프로그램 폴더의 Resumate를 열어요. 실행이 차단되면 도움말을 확인해 주세요.

  1. 설치 파일 공개 여부 확인

    다운로드 단계에서 공식 Windows 파일이 제공되는지 먼저 확인해요.

  2. 설치 파일 실행하기

    다운로드한 -setup.exe를 열고 설치 마법사를 따라가요. Resumate 설치에는 관리자 권한이 필요하지 않아요.

  3. Resumate 실행하기

    설치 후 시작 메뉴에서 Resumate를 열어요. AI 도구가 Git을 요청하면 공식 Git for Windows를 설치해 주세요.

앱 첫 화면에서 두 가지 방법 중 하나를 골라요.

AI 계정 없이도 가능

이력서부터 가볍게 써볼래요

첫 화면 아래의 ‘AI 없이 이력서만 작성하기’를 눌러주세요. 이력서를 작성하고, PDF로 내보내고, 보관함에 정리할 수 있어요.

개인 Claude 유료 계정 필요

코치와 함께 준비할래요

  1. Claude 카드에서 ‘연동하기’ 또는 ‘로그인’을 눌러요.
  2. 처음이라면 공식 Claude Code 설치가 진행돼요. Terminal 또는 PowerShell이 열리면 공식 로그인 안내를 따라주세요.
  3. 브라우저에서 본인의 Claude 계정으로 인증해요. 인증 코드 입력이 필요하면 공식 CLI 창에 입력해요.
  4. 앱에 ‘연결됨’이 표시되면 ‘시작하기’를 눌러요.

Claude 무료 플랜은 지원하지 않아요. AI 사용량은 내 Claude 계정 한도에서 차감돼요. Resumate는 Claude 인증 코드나 토큰을 받지 않아요.

설치 도움말

Mac에서 앱을 열 수 없다고 나와요.
Apple Silicon(M1 이상)과 macOS 13 이상인지 확인해 주세요. 실행이 계속 차단되면 보안 설정을 변경하지 말고, 받은 앱 버전·macOS 버전·오류 메시지를 공식 배포 저장소에 알려주세요. 이력서나 인증 정보는 첨부하지 않아도 돼요.
Windows 설치 파일이 없어요.
아직 공개되지 않은 버전은 다운로드할 수 없어요. 공개 릴리스 목록에서 Windows 설치 파일이 올라왔는지 확인해 주세요. ARM64 Windows는 지원하지 않아요.
AI 로그인을 완료했는데 연결되지 않아요.
브라우저 인증 뒤 공식 Terminal 또는 PowerShell 창의 안내까지 완료해 주세요. 앱은 실제 인증 상태를 확인하며, 최대 5분 뒤 확인을 종료해요. 시간이 지났다면 앱에서 다시 로그인해 주세요. AI 없이 시작한 뒤 설정의 AI 연동에서 연결할 수도 있어요.
새 버전은 어떻게 받나요?
앱 시작 시 업데이트를 확인하고 제공되는 버전이 있으면 안내해요. 모든 시험판이 자동 업데이트되는 것은 아니에요. 릴리스 목록에서 변경 내용과 설치 파일을 확인할 수 있어요.
