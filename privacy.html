1. 적용 범위

이 방침은 곽태훈(이하 “운영자”)이 배포하는 데스크톱 앱 Resumate(macOS·Windows, 이하 “앱”)와 앱 소개 웹사이트(이하 “웹사이트”)에 적용됩니다. 운영자는 「개인정보 보호법」 등 관련 법령을 지키며, 앱이 실제로 어떻게 동작하는지를 기준으로 이 방침을 작성했습니다.

2. 운영자가 수집하는 개인정보

운영자는 앱 사용자의 개인정보를 수집하지 않습니다.

  • 앱에는 운영자 계정·회원가입 기능이 없습니다.
  • 운영자는 사용자의 이력서, 대화, 업로드 파일, 음성, 면접 기록을 받는 서버를 운영하지 않습니다. 앱이 정보를 보내는 곳은 아래 4항에 적은 곳뿐입니다.
  • 앱에는 사용 통계·오류 보고·광고 식별자를 운영자에게 보내는 기능이 없습니다.

사용자가 이메일로 문의하면, 답변을 위해 보낸 사람의 이메일 주소와 문의 내용을 받게 됩니다. 이 정보는 문의 처리에만 쓰고, 처리가 끝나면 지체 없이 삭제합니다. 다만 같은 문제가 반복될 때 참고하기 위해 사용자가 요청하지 않는 한 최대 1년간 보관할 수 있습니다.

아래 정보는 사용자의 컴퓨터에만 저장되며 운영자에게 전송되지 않습니다. 운영자는 이 정보에 접근할 수 없습니다.

폴더 분석에서 제외하는 파일

분석할 폴더를 고르면 .env, 키 파일, .ssh 같은 비밀 정보 파일과 폴더 밖을 가리키는 링크는 AI가 읽지 못하도록 막습니다. 홈 폴더 전체나 인증 정보 폴더는 분석 폴더로 고를 수 없습니다.

Claude Code와 Anthropic

Claude Code 로그인, 인증 정보의 저장·갱신, AI 요청 전송은 Anthropic의 공식 Claude Code가 담당합니다. Resumate는 Claude 로그인 코드·토큰·쿠키를 받거나 인증 정보 파일을 읽지 않으며, 로그인 상태만 확인합니다. Anthropic으로 전송된 정보와 Claude Code가 자체적으로 수집하는 정보의 처리에는 사용자와 Anthropic 사이의 약관과 Anthropic 개인정보 처리방침이 적용됩니다.

웹사이트

웹사이트는 GitHub Pages를 통해 제공하며 쿠키·분석 도구·외부 글꼴을 쓰지 않습니다. GitHub는 보안을 위해 방문자의 IP 주소를 기록·보관합니다. 다운로드 파일도 GitHub에서 제공하므로 다운로드 요청 시 GitHub에 접속 정보가 전달됩니다. 이 정보의 처리와 보관에는 GitHub 개인정보 처리방침이 적용됩니다.

5. 처리 목적

앱이 컴퓨터에 저장하거나 외부로 보내는 정보는 다음 목적에만 쓰입니다.

  • 이력서 진단·첨삭, 프로젝트 성과 정리, 공고 맞춤 이력서·자기소개서 작성, 면접 질문과 답변 평가 등 사용자가 요청한 기능 제공
  • 작업 내용을 다음에 이어서 쓸 수 있도록 보관
  • 앱 업데이트 확인과 설치
  • 문의에 대한 답변(이메일로 문의한 경우)

6. 보유 및 이용 기간

  • 컴퓨터에 저장된 정보: 사용자가 앱에서 지우거나 데이터 폴더를 삭제할 때까지 사용자의 컴퓨터에 남습니다. 운영자는 이 정보를 보유하지 않습니다.
  • Anthropic으로 전송된 정보: Anthropic의 개인정보 처리방침과 사용자의 계정 설정에 따른 기간 동안 보관됩니다.
  • 문의 메일: 2항에 적은 기간 동안 보관합니다.

7. 제3자 제공과 처리 위탁

운영자는 사용자의 개인정보를 제3자에게 제공하지 않으며, 개인정보 처리를 위탁하지 않습니다.

AI 기능을 쓸 때 Anthropic으로 정보가 전송되는 것은 운영자가 제공하는 것이 아니라, 사용자가 본인 계정으로 Anthropic의 Claude Code 서비스를 직접 이용하는 것입니다. Resumate는 사용자의 컴퓨터에서 그 요청을 만들어 Claude Code에 넘기는 역할만 합니다.

9. 기기 권한

  • 마이크: Echo와 면접을 연습할 때 답변을 목소리로 녹음하는 경우에만 씁니다. 한 번에 최대 5분까지 녹음하며, 녹음은 컴퓨터 안의 음성 인식 모델(Whisper)로 글자로 바뀝니다. 녹음 파일 자체는 외부로 보내지 않고, 받아쓴 글만 AI 요청에 포함됩니다. 권한을 허용하지 않아도 글로 답하는 연습은 그대로 쓸 수 있습니다.
  • 파일과 폴더: 사용자가 직접 고르거나 끌어다 놓은 파일과 폴더만 읽습니다.

앱은 위치, 카메라, 연락처, 운영체제 알림 권한을 요청하지 않습니다.

10. 정보주체의 권리와 행사 방법

사용자는 언제든지 자신의 개인정보를 열람·정정·삭제하고 처리 정지를 요구할 수 있습니다.

  • 컴퓨터에 저장된 정보: 운영자가 보유하지 않으므로 사용자가 앱에서 직접 확인·수정·삭제할 수 있습니다. 전부 지우는 방법은 11항을 보세요.
  • Anthropic으로 전송된 정보: Anthropic에 직접 요청하세요. 방법은 Anthropic 개인정보 처리방침에 있습니다.
  • 문의 메일: ender4@naver.com으로 삭제를 요청하면 지체 없이 처리합니다.

법정대리인이나 위임을 받은 사람을 통해서도 권리를 행사할 수 있습니다.

11. 파기 절차와 방법

운영자가 보유하는 개인정보는 문의 메일뿐이며, 보유 기간이 끝나면 복구할 수 없는 방법으로 지웁니다.

컴퓨터에 저장된 정보는 사용자가 직접 지울 수 있습니다. 앱 안에서 이력서·보관함 파일 등을 하나씩 지울 수 있고, 모두 지우려면 앱을 종료한 뒤 아래 순서를 따르세요. 앱을 삭제하는 것만으로는 데이터 폴더가 지워지지 않을 수 있습니다.

macOS

  1. 응용 프로그램 폴더에서 Resumate를 휴지통으로 옮깁니다.
  2. Finder에서 이동 → 폴더로 이동을 열고 다음 폴더를 각각 지웁니다.
    • ~/Library/Application Support/com.resumate.app
    • ~/Library/Application Support/resumate
    • ~/Library/WebKit/com.resumate.app
    • ~/Library/Caches/com.resumate.app
    • ~/.resumate
  3. 휴지통을 비웁니다.

Windows

  1. 설정 → 앱에서 Resumate를 제거합니다.
  2. 파일 탐색기 주소창에 다음 경로를 넣고 각 폴더를 지웁니다.
    • %APPDATA%\com.resumate.app
    • %LOCALAPPDATA%\com.resumate.app
    • %USERPROFILE%\.resumate

다운로드 폴더로 내보낸 파일은 따로 지워야 합니다. Claude Code를 다른 용도로 쓰지 않는다면 Claude Code의 로그아웃·삭제 방법은 Anthropic 안내를 따르세요. Claude Code에서 로그아웃하면 같은 계정을 쓰는 다른 도구의 로그인도 함께 풀릴 수 있습니다.

12. 안전성 확보 조치

  • 앱 데이터 폴더와 보관함 폴더는 macOS에서 현재 사용자만 접근할 수 있도록 권한을 제한합니다.
  • 앱 내부 통신은 같은 컴퓨터 안(127.0.0.1)에서만 이루어지며, 실행할 때마다 새로 만든 인증 값이 있어야 응답합니다.
  • PDF·음성 처리용 임시 파일은 현재 사용자만 읽을 수 있게 만들고 처리가 끝나면 지웁니다.
  • AI가 분석 폴더 안의 비밀 정보 파일을 읽지 못하도록 도구 권한을 제한하고, AI에게는 파일 수정·명령 실행 권한을 주지 않습니다.
  • 업데이트 파일은 서명을 검증한 뒤에만 설치합니다.
  • Claude Code를 앱으로 설치할 때는 공식 배포처에서 받아 체크섬을 확인합니다.

컴퓨터에 저장된 정보는 별도로 암호화하지 않습니다. 운영체제의 디스크 암호화(macOS FileVault, Windows BitLocker 등)와 사용자 계정 잠금을 함께 쓰기를 권합니다.

13. 자동 수집 장치
